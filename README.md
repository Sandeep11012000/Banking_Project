# Banking_Project
## Project Overview
This project addresses the challenges faced by a bank's operations team in processing high-value transactions due to a post-COVID spike in online activity. Manual processes caused SLA breaches and customer refunds.
## Role
**Business Analyst (BA)** - Led stakeholder analysis, captured requirements, and delivered the BRD with AS-IS and TO-BE Process flows.
## Deliverables
- Business Requirements Document (BRD).
- AS-IS Process Diagram.
- TO-BE Process Diagram.
## Outcome
- Manual process (5+ mins) reuced to 30 seconds via automation.
- 96% reduction in refunds.
- Seamless data sync between online and legacy systems.
